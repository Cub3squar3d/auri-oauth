Privacy policy

Last updated: 1 November 2026

Auri is a private, self-hosted automation client used by a single individual on their own server. It is not a public service, has no other users, and has no employees or third parties with access to its data.

What Google data it accesses

With your explicit consent granted through Google's OAuth flow, the client requests the following scopes, and uses each only to perform actions you ask it to perform:

  • gmail.readonly, gmail.modify — to search, read and label the owner's own mailbox
  • gmail.send — to send mail only when the owner explicitly requests it
  • calendar — to read and manage the owner's own calendar
  • drive — to read and manage files in the owner's own Drive
  • spreadsheets, documents — to read and edit the owner's own Sheets and Docs
  • contacts.readonly — to look up the owner's own contacts

How the data is stored

Data retrieved from Google is held only on hardware owned and controlled by the account owner, in a private network. OAuth credentials are stored in a file readable by that server's runtime only.

Sharing

No Google user data is sold, rented, transferred, or disclosed to any third party. It is not used for advertising, profiling, or to train machine-learning models. It is used solely to fulfil the owner's own requests.

Retention and deletion

Cached data is deleted when it is no longer needed for the task at hand. Access can be revoked at any time at myaccount.google.com/permissions, which immediately invalidates the stored credentials.

Limited Use disclosure

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
